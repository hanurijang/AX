## 정확성 보완

- M20의 회귀계수 그림에서 값을 축 경계로 잘라 그리던 처리를 없앴다. r=0.99 자료에는 첫 계수가 10.54까지 올라가며, 두 계수의 점 4개가 이전 공동 표시 범위를 벗어난다. 새 공통 축은 실제 값을 보존한다. VIF 곡선도 30에서 자르지 않아 r=0.985의 약 33.585를 그대로 그린다. 다항곡선은 함수값을 바꾸지 않고 SVG clipping으로 표시 영역만 제한한다.
- M21은 반올림한 0.67을 정확한 분모처럼 사용하지 않고 2/3으로 OR=6을 설명한다. M22의 이항 반응은 0~m이며 무제한의 비음수 정수가 아니다.
- M23의 Wald 표는 원자료의 푸아송 최대가능도와 관측 정보행렬로 다시 계산했다. AIC 비교는 동일한 반응·관측·가능도 정의가 전제다.
- M24의 선택 조건은 양의 효과이면서 양측 p<0.05인 경우다. 전체 유의 결과를 모두 공개한 설정으로 설명하지 않는다. 개별 원자료를 새로 복원하지 않고 저장된 도수·요약을 사용한다.
- M26의 45/125=36%는 주어진 사전 비율과 검정력 아래 유의 결과가 귀무가설에서 나올 조건부 비율이다. 일반적인 FDR 정의와 동일시하지 않는다. 축 하한보다 작은 베이즈 인수는 경계에 표시하되 `B < 0.032`를 밝혀 잘못된 좌표 해석을 막았다.
- M27의 기대 거짓 양성 수는 모든 귀무가설이 참이고 유효한 p값일 때의 기댓값이다. 독립성을 요구하는 적어도 한 번의 오류 확률과 구분한다.
- M29의 표준차 분모는 매칭 전 두 집단의 표본분산을 평균한 뒤 제곱근을 취한 값이다. 전후 동일한 분모를 쓴다. 69쌍의 한 공변량 균형이 미측정 교란 부재나 전체 집단의 인과효과를 보장하지 않음을 본문에 남겼다.
