## 조사와 수정

22차의 경계·최종 5개 모듈을 제외한 **과정 내부 32개 모듈**을 조사했다. NEXT 제목은 모두 실제 다음 모듈 title과 일치했지만 이동 링크가 없어, 안내 후 홈에서 다음 학습을 다시 찾아야 했다. 22차와 같은 일반 HTML 링크·포커스 스타일을 추가했다. M10→M11은 현행 `M11_가설검정의원리와p값_v1.1.html`로 연결한다.

마지막 슬라이드의 하단 ‘다음’은 계속 비활성화하며, 안내 카드의 ‘다음 모듈 학습하기’ 링크를 명시적으로 눌러 이동한다. 슬라이드를 넘기다 자동으로 다른 문서를 여는 동작은 추가하지 않았다. 기존 통계 계산·문항·실습·저장 자료는 유지했다.

안내 문구 2곳도 대상 모듈의 기존 엄밀화와 맞췄다.

- M14→M15: 모든 t검정 반복을 금지하는 문장 대신, 여러 쌍의 **무보정** 반복이 전체 1종 오류 확률을 키울 수 있다고 설명했다. 분산분석과 비교 범위에 맞는 다중비교로 연결한다.
- M25→M26: ‘p값 대신’·‘논문 결론이 옳지 않을 확률’이라는 포괄적 표현을 p값/BF의 차이와 **가정한 모형에서 유의 결과의 위양성 비율**로 정리했다. 실제 논문 전체의 오류율이나 개별 연구의 사후확률로 읽지 않도록 대상 모듈의 보충과 정합화했다.
