# 홈 UI/UX 개선

검증일: 2026-10-29(한국 시간).

`index.html`을 학습 시작과 모듈 탐색 중심으로 개편했다. 스타일과 동작은 `assets/home.css`, `assets/home.js`로 분리했다. 외부 프레임워크·폰트·빌드 도구는 추가하지 않았다.

- 긴 모듈 나열을 과정 소개 카드와 펼칠 수 있는 목록으로 정리했다. 기존 과정 5개와 모듈 37개의 목적지·이름을 유지하고 모듈 바로 가기를 추가했다.
- 모듈명·번호·주제 키워드 검색, 과정 필터, 결과 수, 일치 제목 강조, 결과 없음과 초기화를 제공한다. 검색/필터는 URL에 남아 새로고침과 뒤로 가기에서도 복원된다. 한글 조합 중에는 필터링을 보류한다.
- 처음에는 M01 시작 링크를, 홈에서 모듈을 연 뒤에는 최근 모듈 다시 열기를 제공한다. 저장하는 값은 이 브라우저의 모듈 ID뿐이다. 완료율이나 슬라이드 진도를 추적하는 기능은 아니다. 기록을 지울 수 있고 저장소 차단 시에도 탐색은 동작한다.
- 모바일 배치·가로 스크롤 과정 필터·터치 영역, 시스템 다크 모드와 동작 줄이기 설정을 지원한다. 건너뛰기 링크, 검색 단축키 `/`, 표시되는 키보드 초점을 추가했다.
- 의견 폼은 기본 `dialog`의 모달 초점 관리·Escape·닫기 후 초점 복귀를 사용한다. 기존 FormSubmit 목적지는 유지했다. 입력 검증, 제출 중 상태, 응답 제한 시간을 추가하고 실패 시 입력을 보존한다. 수신 활성화 실패를 ‘전달됨’으로 안내하던 문구는 접수 미확인으로 바로잡았다.
- JavaScript가 꺼져 있어도 과정 링크와 기본 `details`의 37개 모듈 링크를 사용할 수 있다.

## 확인한 범위

시스템 Chromium·Playwright와 로컬 HTTP 서버로 검사했다. 검사 파일과 결과·화면은 저장소 밖 `/workspace/ax-setup/home-review/`에 있다(`check_home.py`, `result.json`).

- 홈·5개 과정·37개 모듈의 43개 로컬 목적지 HTTP 200과 파일 존재 확인.
- 검색, 과정과 검색의 결합, 일치 표시, 초기화, 결과 없음, 전각 번호, 한글 조합, URL 복원 확인. 입력 문자열은 HTML로 삽입하지 않는다.
- 실제 모듈 열기→브라우저 뒤로 가기→최근 기록 복원·초기화 확인. 잘못된 JSON·허용되지 않은 ID·저장 데이터의 임의 URL은 목적지를 바꾸지 못한다.
- 의견 폼의 빈 의견·잘못된 이메일, 과정별 모듈 선택, 모의 성공·서버 실패·수신 활성화 실패·잘못된 JSON·네트워크 실패 확인. **모의 요청 5건을 가로채 검사했으며 실제 의견은 발송하지 않았다.** 실제 서비스의 수신함 도착 여부는 이번 검사 범위 밖이다.
- 1440×1000, 768×1024, 390×844, 320×568, 다크 모드·동작 줄이기에서 검색/필터·의견 창 확인. 문서의 가로 넘침과 JavaScript 실행 오류 없음. 대표 화면 직접 확인.
- JavaScript 비활성화 시 모듈 37개 탐색, `localStorage` 접근 차단 시 검색·모듈 이동 확인.
- 기존 모듈 37개와 콘텐츠 검수 기록 12개의 파일 해시가 홈 작업 전후 모두 동일함을 확인했다. 교재 10~12차의 기존 검증 결과를 확인하고 수정된 8개 모듈의 JavaScript 구문 검사도 통과했다.
- `node --check assets/home.js`, `git diff --check` 통과.

검증은 위 브라우저와 조건에 한정한다. 서버 없이 정적 파일로 제공할 수 있으며 파일 구조를 함께 배포해야 한다. 교재 10~12차 변경과 이번 홈 개선은 별도 커밋으로 기록한다.
