## 원문과 보충의 경계

- 원문 320쪽의 MLE/빈도주의 설명을 모든 빈도주의 추론이 점 하나만 제공한다는 뜻으로 확대하지 않았다. 빈도주의도 구간을 제공한다는 설명은 기존 1차 보완이며 이번에는 개요·분류·정리에 남은 불일치를 맞췄다.
- 강도 10개·σ=20·두 사전분포는 모듈의 가상 설정이다. 실제 강종 시험 결과라고 주장하지 않는다. 균등 사전의 n≥1 사후는 엄밀히 400~700에서 절단된 정규분포이며 현재 값들이 경계에서 멀어 정규근사를 유지했다. 모든 범위·자료에 이 근사가 좋은 것은 아니다.
- 새 시험편 SD와 확률은 독립 정규·알려진 σ 모형 및 범위 사전의 정규근사에서 계산한 보충이다. μ의 95% 신용구간은 개인값 예측구간이 아니다. 실제 품질 채택 기준이나 생산 안전성 검증 결과로 해석하지 않는다.
- 원문 324쪽의 WAIC/KL 연결은 예측 성능 추정의 조건과 유한 자료의 한계를 보충했다. 이번에 WAIC나 실제 KL을 자료로 산출하거나 모형을 선택한 것은 아니다.
- 원문 380쪽의 ‘시간 간격을 작게 한다’는 설명에 배율과 변화율의 단위 관계를 보충했다. 교재와 모듈의 배율·시간 단위가 항상 동일하다고 가정하지 않는다.
- 원문 385쪽 식 13.11은 정규화한 감수성 비율을 곱한 초기 값을 R₀로 적는다. 모듈은 기존 표기인 **기초 R₀=β/γ**와 **현재 Rₜ=(β/γ)S/N**를 구별했다. 교재의 기호를 그대로 복사한 것은 아니며 초기 S/N≈1에서 둘이 가깝다는 관계를 설명한다.
- 최종크기 그림은 기존의 초기 감염 비율을 0으로 보내는 이상화 대신 궤적과 같은 (S,I,R)=(999,1,0)을 사용한다. β·γ가 시간에 일정하고 재감염·출생·유출이 없는 기본 SIR에서 z∞=1−.999 exp(−R₀z∞)를 푼다. 확률적 소멸·유한 인구 감염 과정의 분포를 계산한 것은 아니다.
- 30일 개입 시나리오의 약 692/420/236명은 기존 가상 결과와 독립 수치해를 대조했다. 실제 β·γ를 새로 추정하거나 대책 효과를 검증한 것은 아니다. 조작 실습은 계속 150일을 계산하며 이를 최종 규모라고 부르지 않도록 수정했다.
