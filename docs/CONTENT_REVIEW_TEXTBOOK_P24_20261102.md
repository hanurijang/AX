## 범위와 확인 결과

전체 37모듈의 참고자료 **161항목·47개 고유 URL**을 추출했다. 목록은 [참고자료 CSV](REFERENCE_INVENTORY_P24_20261102.csv)에 보존한다. `module`·`n`은 모듈별 자료 번호이며 `date`는 이번에 갱신한 날짜가 아닌 기존 확인 기록이다. `external_verification`은 이번 외부 접속 확인 여부다.

번호의 연속·중복, 제목/출처 누락, 용어해설의 출처 번호와 목록 대응, 동일 URL의 제목·출처 충돌을 검사했다. 47개 URL은 모두 HTTPS이며 호스트·공백·DOI 경로 형식을 검사했다. 고유 DOI URL은 26개다. 이번 검사에서 위 메타데이터 불일치는 발견되지 않았다. 서지 정보가 실제 원문과 일치한다는 외부 검증을 뜻하지 않는다.

관리형 환경은 HTTP 제한 정책이 적용 중이며, 47개 URL의 호스트가 모두 현재 허용 목록 밖이다. 우회나 외부 접속 요청을 수행하지 않았다. 따라서 HTTP 성공·404·리디렉션·자료 본문 일치·링크 최신성을 새로 판정하지 않았고 기존 URL과 확인일도 바꾸지 않았다. CSV의 ‘미실행’은 사이트 장애를 뜻하지 않는다. 원본 PDF의 통계 내용·문항·계산을 수정하거나 다시 검증한 차수가 아니다.

## 확인한 문제와 수정

| 문제 | 수정 |
|---|---|
| 참고자료 제목은 일반 텍스트이고 긴 URL 자체가 링크여서 링크의 목적을 읽기 어려움 | 제목을 링크로 표시하고 출처·기존 확인일을 별도 줄로 분리. URL 주소는 href에 그대로 유지 |
| 새 탭으로 열리는 링크에 화면상 안내가 없음 | 각 제목 링크에 ‘새 탭’ 표시. 기존 target=_blank·noopener 유지 |
| 참고자료 링크의 키보드 포커스 표시가 명시되지 않음 | focus-visible 윤곽과 목록 안쪽 여백 추가 |
| 자료 목록에 포커스가 있어도 전역 PageUp·PageDown 및 좌우 방향키 처리가 슬라이드 이동을 실행·기본 동작을 막음 | 참고자료 안에 포커스가 있으면 목록의 기본 키 동작을 허용. 목록 밖에서는 기존 슬라이드 단축키 유지 |

37모듈에 동일하게 적용했다. 출처 메타데이터·원본 URL·용어해설의 인용 번호·통계 실습은 유지했다. 긴 제목과 출처는 목록의 기존 스크롤 영역에서 마지막 항목까지 읽을 수 있다. 22~23차의 다음 학습 이동도 유지했다.

## 재실행 가능한 검사

```sh
PYTHONDONTWRITEBYTECODE=1 python scripts/reference_inventory.py
PYTHONDONTWRITEBYTECODE=1 python scripts/review_p24.py
```

Python 3.10+, Node, Playwright, Chromium이 필요하다. 두 번째 명령은 `scripts/review_p17.py`의 공통 화면 도우미를 사용한다. 목록 도구는 외부 요청 없이 소스 배열의 번호·메타데이터·URL 형식을 검증하고 CSV를 생성한다. 외부 검증 상태는 실행 환경의 정책에 따라 표시되며, 이번 보존 CSV와 다른 환경에서는 그 값이 달라질 수 있다. 정책 파일이 없거나 허용된 호스트라도 외부 검증 완료로 표시하지 않는다.

브라우저 검사는 외부 요청을 차단한 로컬 임시 HTTP 서버에서 1280×800과 1024×768로 실행한다. 모든 참고자료 제목·메타데이터·URL·새 탭/noopener 속성, 링크별 포커스와 스크롤 영역 안 표시, 출처 번호 대응을 확인한다. 목록이 넘치는 조건에서는 PageDown·PageUp 스크롤, 목록 안 방향키로 슬라이드가 바뀌지 않음, 목록 밖의 이전 슬라이드 단축키 정상 작동을 확인한다. 전체 37개 마무리에서 다음 학습 이동·최종 목록 복귀도 Enter와 클릭으로 재검사한다.

최종 결과: **37화면 × 2크기 = 74조건, 참고자료 링크 322회 포커스 검사, 다음 학습 Enter/클릭 148회 이동을 통과**했다. 검사 영역 넘침·SVG 글자 잘림·실행 오류는 각각 **0건**이다. 정적 목록 검사도 37모듈·161항목·47 URL을 통과했고 외부 요청은 0회다. 37개 인라인 JavaScript 및 새 Python 2파일 구문, `git diff --check`를 확인했다. 전체 모듈의 REFS·GLOSSARY·QUIZ 배열은 기준 커밋과 문자 단위로 같고 홈 3파일도 바이트가 같다. M07 1280×800·M14 1024×768 캡처를 직접 확인했다. Python 3.12.14·Node 24.19.0·Playwright 1.62.0·Chromium 154.0.8037.57에서 실행했다. 초기 검사 도구의 배열 접근·키보드 모드 설정을 바로잡은 뒤 최종 전체 검사를 재실행했다.

외부 참고자료 본문의 타당성·최신성·권리 검토와 실제 서비스 배포·세로 모바일·전체 브라우저는 이번 범위에 포함하지 않는다. 외부 URL 접근 확인은 허용된 실행 환경에서 남은 후속이다. 다음 로컬 점검 후보는 참고자료 이외의 키보드 단축키와 문항·실습 조작 간 충돌이다.
