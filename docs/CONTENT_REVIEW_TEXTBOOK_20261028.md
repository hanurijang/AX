## 원문 확인 방법과 쪽수

원본은 텍스트 레이어가 없는 스캔본이다. Tesseract의 한국어·영어 OCR로 관련 절을 탐색하고, 핵심 쪽(통합 PDF 37·39·211·216·240·243·308쪽)은 원문 이미지도 직접 확인했다. OCR 문자열만으로 수식·숫자·문구를 확정하지 않았다.

여기서 **쪽수는 분할 전 PDF의 1부터 시작하는 통합 순번**이다. 인쇄면의 쪽수라고 추정하지 않는다.

| 업로드 파일 | 통합 순번 | 파일 안 쪽수 계산 |
|---|---|---|
| `통계101_part1_p1-134.pdf` | 1~134 | 통합 순번과 같음 |
| `통계101_part2_p135-268.pdf` | 135~268 | 통합 순번 − 134 |
| `통계101_part3_p269-402.pdf` | 269~402 | 통합 순번 − 268 |

로컬 작업 계획·원문 렌더링·OCR·파일 해시: `/workspace/AX/ref/textbook-review/`.

- `PLAN.md`: 수정 계획과 진행 현황.
- `source-manifest.json`: 업로드 파일명·크기·SHA-256.
- `pdf-NNN.png` / `pdf-NNN.txt`: 해당 통합 순번의 원문 이미지 / OCR 보조 결과.
- 기존 `.gitignore`의 `/ref/` 규칙을 유지했다. PDF·스캔·OCR을 Git 이력에 추가하지 않는다. 이 문서는 원문을 장문 재현하지 않고 변경 이유와 검증 근거를 보존한다.

### 교재와 보충 설명의 경계

1. 교재 37쪽의 남성으로 범위를 제한하는 예는 연구 목적을 명시적으로 제한하는 선택으로 반영했다. 원래 목표가 자료의 누락만으로 자동 변경된다고 가르치지 않는다.
2. 교재 39쪽의 변동 인구 설명은 기준시점의 유한성과 시간적 변화로 나누었다. 이 부분은 정의를 명확히 하는 보완이다.
3. 교재 211~212쪽의 ‘영향’은 모형의 조건부 연관으로 설명하고, 308쪽의 인과 조정 주의사항을 선행 모듈에 연결했다. 계수 하나로 인과를 확정하지 않는다.
4. 교재 216쪽의 사용 조건은 공통 기울기 모형의 가정과 분석 선택 지침으로 풀어 설명했다. 공변량의 p값이 유의해야만 공분산분석이 수학적으로 가능하다는 뜻으로 전달하지 않는다.
5. **오프셋의 전개와 준푸아송 대안은 확인한 교재 절에 직접 제시된 공식·문장이 아니라 실무 보충**이다. s-4-1c를 실무 보충으로 표시했다. E>0 및 λ가 E에 비례한다는 전제를 함께 설명한다.
6. 포아송 회귀의 조건부 분산은 Var(Y|X,E)=λ(X,E)이다. 전체 자료는 Var(Y)=E[λ]+Var(λ)가 될 수 있으므로 전체 분산이 평균보다 크다는 이유만으로 조건부 과분산을 확정하지 않는다. 이 식은 보충 설명의 수학적 근거다.

## 예시자료·수치 환류

교재의 예시 계수를 현재 모듈의 다른 가상자료에 그대로 대입하지 않았다.

- **M19:** 모듈에 있는 성인 20명 자료(HT·WS·WT)를 독립적으로 최소제곱 적합했다. 절편 −66.7720247, 키 0.5377320, 허리 0.5345506으로 기존 표시 −66.772, 0.538, 0.535를 재현했다. 표준화 설명에서 반응변수 단위가 남는 점도 유지했다.
- **M22:** 교재 240쪽 꽃 예시 계수는 약 a=−2.68, b=0.594이다. 모듈의 FX·FY는 별도 가상자료로, Poisson 로그가능도를 독립 최적화하면 a=−2.5411938, b=0.5773423이다. 기존 모듈의 −2.54, 0.577이 이 자료와 맞으므로 유지하고 ‘모듈의 가상 꽃 데이터’임을 명시했다.
- **오프셋 보충:** A 20건/10시간, B 40건/20시간은 모두 관측 발생률 2건/시간. 기대 발생률 2일 때 기대 건수는 20·40건으로 노출량에 비례한다. 이는 관측률이 같다는 예시이며 모집단의 실제 발생률 동일성을 증명하는 검정 결과는 아니다.
- **과분산 그림의 제1종 오류 약 0.27:** 기존 모듈의 모의실험 예시값으로 구분했다. 이번에 2,000회 실험을 다시 수행하거나 교재의 실측 수치로 확인했다고 주장하지 않는다.
