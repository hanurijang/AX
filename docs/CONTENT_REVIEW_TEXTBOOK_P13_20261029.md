## 원문과 보충의 경계

- 원문 156쪽의 대응 설계 설명을 유지한다. 모듈의 복용 전 혈압 7개는 기존에 모듈에서 정한 예시값이며, 교재의 원래 전후 관측자료라고 주장하지 않는다. 대응/독립 검정 중 작은 p값을 선택하는 절차를 권하지 않는다.
- 순위합의 동일 분포 가설과 위치 이동 해석을 구별한 것은 기존 수정이다. 이번에 추가한 정확 순열 계산은 **현재 모듈의 신약·위약 각 7개 값**을 재계산한 보충이며 원문에 같은 수치가 실렸다는 뜻이 아니다.
- 정확 순열은 합친 14개 값을 고정하고 동일 분포 귀무가설 아래 표지를 교환할 수 있다는 조건에서 7명씩 나눈다. 동점은 평균 순위로 처리하고, 중심 52.5에서 관찰값 이상 떨어진 순위합을 양측 꼬리로 센다. 소프트웨어마다 ‘exact’ 옵션의 동점 처리·양측 규칙이 다를 수 있다.
- 원문 167쪽의 ‘한 집단이라도 비정규이면 KW’ 권고는 연구 질문과 가정을 보충해 수정했다. KW가 언제나 평균·중앙값 차이를 검정하거나 모든 분산 차이에 강건하다는 뜻이 아니다. Welch ANOVA도 독립성과 분포·표본 조건을 확인해야 한다.
- 비료 데이터의 KW p값은 자유도 2의 카이제곱 근사다. 작은 표본에서 실제 오류율을 새로 모의실험한 결과로 표시하지 않는다. 스틸·스틸–드와스·던넷·윌리엄스의 실제 p값을 이번에 새로 계산하지 않았다.
- 전체 F검정 뒤 적절히 보정된 비교를 하는 것 자체가 FWER를 높인다는 잘못된 설명은 2차에서 이미 바로잡았다. 이번 신규 수정으로 다시 집계하지 않는다.
