## 조사와 수정

이번 범위는 과정 경계 M07→M08, M16→M17, M23→M24, M29→M30 및 마지막 M37의 마무리 화면이다. 원본 PDF의 통계 내용은 변경하지 않았다. 다음 학습의 제목·설명은 현행 대상 모듈의 title·학습개요와 과정 목록을 근거로 대조했다. 이전 차수의 원본 대조와 수치 검증을 재수행했다고 주장하지 않는다.

기존 NEXT의 제목·설명과 대상 파일은 일치했지만, 마무리 안내는 텍스트뿐이었다. 마지막 슬라이드에서는 하단 ‘다음’도 비활성화되어 다음 과정으로 가려면 홈에서 다시 찾아야 했다. 명시적인 일반 HTML 링크를 안내 카드 안에 추가했다. 슬라이드의 ‘다음’은 기존처럼 마지막에서 비활성화하며 자동으로 다른 문서를 열지 않는다.

## 검증

재실행: `PYTHONDONTWRITEBYTECODE=1 python scripts/review_p22.py`. Python 3.10+, Node, Playwright, Chromium이 필요하다. `scripts/review_p17.py`의 공통 화면 도우미를 사용한다. 결과·화면은 Git 제외 `ref/review-p22/`에 저장한다.

임시 로컬 HTTP 서버에서 Chromium, 외부 요청 차단, 1280×800 및 1024×768로 검사한다. 실제 단계 버튼과 슬라이드의 다음 버튼으로 마무리에 도착한 뒤 다음을 확인한다.

- 5개 출발 화면 × 2개 크기 = 10조건. 각 조건에서 Enter와 클릭 모두 검사해 총 20회 이동.
- 링크의 상대 경로·대상 파일 존재·과정 소속·다음 모듈 제목 일치. 대상 HTTP 응답 및 실제 학습개요/과정 목록 도착.
- 마지막 슬라이드의 다음 비활성화, 링크 포커스와 Tab 왕복·포커스 윤곽, 하단 바 및 화면 밖 겹침 방지.
- 참고자료의 마지막 항목까지 스크롤 접근 및 마지막 링크의 포커스 가능 여부. 외부 참고자료는 열지 않는다.
- 마무리 화면의 검사 영역 넘침·SVG 글자 잘림과 JavaScript 실행 오류. 수정한 5개 인라인 스크립트의 Node 구문 검사.

최종 결과: **10조건·20회 이동 모두 통과**. 검사 영역 넘침·SVG 글자 잘림·실행 오류는 각각 0건이다. 참고자료 마지막 항목 접근도 10조건에서 확인했다. M07 1280×800과 M37 1024×768 캡처를 직접 확인했다. JavaScript·Python 구문, `git diff --check`, 홈 3파일의 기준 커밋과 바이트 일치도 확인했다.

이번에 교재 본문·문항·실습의 전체 브라우저 검사를 반복하지 않았다. 세로 모바일·모든 브라우저·외부 URL 최신성·실제 서비스 배포는 검사 범위 밖이다. 참고자료 없는 M37의 제목 분기는 소스로 정합화했으며 실제 자료를 제거해 실행하지 않았다. 다음 23차 후보는 과정 내부 모듈의 마무리 안내·이동 점검이다. 이번 5개 경계 이외의 모듈에 이동 링크가 있다고 일반화하지 않는다.
