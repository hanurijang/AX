작업일: 2026-11-02(한국 시간). 기준 커밋 `cd6d0b7247feec443fd98e2466c0d67ec259cc33`. 시작 작업 트리는 깨끗했고 fetch 후 원격 main과 차이는 `0 0`이었다.

## 문제 재현과 수정

M01·M14·M37에서 문항 보기·분류 카드·도움말에 포커스를 두고 실제 오른쪽 방향키를 눌렀다. 모두 각각 q1→q2, p2→p3, p1→p2로 이동했다. Ctrl+오른쪽 방향키도 q1→q2로 이동했다. **3모듈 × 4상황 = 12회**에서 같은 문제를 재현했다. 이전 전역 핸들러는 참고자료와 range 입력만 제외해 다른 조작 요소와 수정키를 포함한 명령까지 슬라이드 이동으로 처리했다.

37개 모듈의 키보드 핸들러를 동일하게 보완했다.

| 키 입력 위치·상태 | 수정한 동작 |
|---|---|
| 문항 보기·목표 이동·단계·실습 버튼, 분류 카드·분류 칸, 링크, 도움말 summary | 슬라이드 단축키가 개입하지 않음. Enter·Space 등 해당 요소의 동작 유지 |
| 입력·편집 요소 | 기본 입력 키 동작 유지. 기존 range 조작 보호도 유지 |
| 참고자료 목록 | 24차의 목록 스크롤·링크 키 동작 유지 |
| Ctrl·Alt·Meta·Shift가 포함된 입력, 조합 중인 입력, 이미 처리된 이벤트 | 슬라이드 명령으로 처리하지 않음 |
| 본문 배경 또는 하단 이전/다음 버튼 | 기존 좌우 방향키·PageUp·PageDown의 슬라이드 이동 유지 |

키보드로 도움말을 여는 화면 검사에서 M01~M06의 본문·피드백 높이 부족도 발견했다. 이 6모듈의 실습 피드백 문단 여백·축소와 도움말 간격을 보정했다. 초기 넘침 검출을 통과로 처리하지 않고 보정 후 전체 검사를 재실행했다.

하단 이전/다음은 슬라이드 이동을 위한 명시적 요소라 단축키를 계속 허용한다. 다른 요소에서는 이벤트의 기본 동작을 취소하지 않는다. 참고자료 표시·통계 내용·문항·실습 계산·자료·배열과 다음 학습 URL은 변경하지 않았다. 원본 PDF 통계 내용을 재대조하거나 계산 전체를 재검증한 차수가 아니다.

## 실행 가능한 검사

```sh
PYTHONDONTWRITEBYTECODE=1 python scripts/review_p25.py
PYTHONDONTWRITEBYTECODE=1 python scripts/review_p24.py --output ref/review-p25/reference-regression
```

Python 3.10+, Node, Playwright, Chromium과 공통 `scripts/review_p17.py`가 필요하다. 외부 요청을 차단한 로컬 HTTP 서버를 사용한다. 첫 번째는 1280×800에서 전체 37모듈을 검사한다.

- 문항 보기·단계 버튼·목표 버튼·도움말·카드·분류 칸·실습 버튼의 7종에 좌우 방향키·PageUp·PageDown을 실제 입력해 슬라이드 유지 확인.
- 정답 보기를 Enter로 채점하고 복귀 버튼으로 본문 이동, 목표 버튼의 Enter 이동 확인.
- 도움말 Enter 열기·Space 닫기, 카드 Enter 선택·Space 해제·다시 선택, 분류 칸 Space 배치, 초기화 Enter, 실습 버튼 Enter 동작 확인.
- 각 모듈의 실제 range 입력 1개에서 방향키로 값 변경과 슬라이드 유지 확인. M31처럼 실습 1에 range가 없으면 실습 3을 사용.
- 본문에서 수정키 4종과 오른쪽 방향키 조합 시 슬라이드 유지. 일반 방향키·PageUp/Down 및 하단 버튼 포커스에서 단축키 이동 확인.
- 조합 중·기처리 이벤트는 합성 KeyboardEvent로 방어 조건 검사. 실제 한국어 IME·OS의 모든 단축키를 검증했다는 뜻은 아님.
- 문항 채점·도움말 펼침·카드 배치·실습 실행 화면의 검사 영역 넘침·SVG 글자 잘림·실행 오류 검사.

두 번째 명령은 24차의 전체 참고자료·학습 이동 회귀 검사다. 두 화면 크기에서 참고자료 포커스·PageUp/Down 스크롤과 목록 밖 하단 버튼 단축키, 다음 모듈·최종 과정 복귀를 확인한다. 참고자료 외부 URL의 접속은 수행하지 않는다.

최종 결과: **37모듈·조작 키 1,036조건·수정키 148조건·방어 이벤트 74조건·일반 슬라이드 이동 222조건·range 입력 37개**를 통과했다. 각 모듈에서 문항·복귀·목표·도움말·카드·초기화·실습 버튼의 기본 키 조작도 확인했다. 검사 영역 넘침·SVG 글자 잘림·실행 오류는 각각 **0건**이다. 24차 회귀도 74화면 조건·참고자료 포커스 322회·다음 학습 이동 148회를 통과했다. 전역 키보드 보정 후 회귀를 실행했으며 이후 추가한 CSS는 실습 단계에만 적용된다. 최종 키보드 검사는 그 CSS까지 반영해 전체 재실행했다.

37개 인라인 JavaScript·새 Python 구문 및 `git diff --check`를 통과했다. 전체 REFS·GLOSSARY·QUIZ 배열과 NEXT 설정은 기준 커밋과 문자 단위로 같고 홈 3파일도 바이트가 같다. Python 3.12.14·Node 24.19.0·Playwright 1.62.0·Chromium 154.0.8037.57에서 실행했다. 검사 도구의 M06 버튼 선택자를 실제 클래스 구성에 맞게 조정한 뒤 최종 전체 실행을 수행했다.

모든 range 입력 조합·실제 IME·스크린리더·OS별 단축키·터치·세로 모바일·전체 브라우저·실제 배포는 이번 범위 밖이다. 외부 47 URL 접속·본문 대조는 24차에 기록한 환경 제한에 따른 별도 후속으로 남긴다. 다음 후보는 단계 이동·문항 복귀·실습 초기화 후의 포커스 위치와 Tab 순서 점검이다.
