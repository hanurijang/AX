## 우선 해결할 근거

1. **SVG 627개에 논리 크기 12px 미만 라벨이 있고, 그중 248개에는 10px 미만 라벨이 있다.** 크기 측정에 기반한 정돈 후보이며 실제 판독성은 화면 배치·표시 크기로 검토해야 한다. CSS 전체 글자 확대를 적용하면 기존 축·범례와 겹칠 수 있으므로 그림별로 재배치한다.
2. **HTML 표 37개 모두 머리글은 있지만 caption과 scope가 없다.** 현행 표의 의미와 수치는 유지하면서 표 제목·머리글 연결을 보완한다. SVG 안에 그린 계수·부하량 등의 표는 별도 재작성/분할 대상이다.
3. **M05 소득 그림은 좁은 구간과 극단값을 축 생략 기호로 붙여 놓았다.** 전체 범위와 확대 분포, 전후 요약표로 나눈다. 모듈의 새 가상 자료를 유지하며 원문의 5,090/6,030과 모듈의 5,088/6,028을 섞지 않는다.
4. **M31 trace는 전체 체인이 아니다.** `TRA`, `TRB`는 각각 5×150개의 반올림 값이다. 표시 코드에서 단계 간격을 10으로 붙이고 1,500단계까지만 보여 준다. 이것으로 번인 후 5×5,000 표본의 ESS·R-hat을 계산하면 안 된다.
5. **M31 도수와 전체 표집 수가 다르다.** `DH` 50개 구간의 합은 24,999, 설명은 25,000이다. 원체인이 없으므로 어느 구간의 1개가 빠졌는지 결정할 수 없다. `PA`, `PB`도 구간 도수 요약만 남아 있으며 합은 각각 27,962/27,968이다. 이것을 같은 전체 표본수라고 임의로 맞추거나 잘린 꼬리라고 확정하지 않는다.
6. **M31에서 수학 값을 제한해 그리는 코드가 확인됐다.** trace의 최솟값 148.8은 150으로 제한되고, 푸아송 곡선은 30에서 평평해진다. 저장된 a=−2.65, b=0.589에서 x=10.5의 값은 약 34.28이다. 원주율 실습도 축 범위 2.6~3.7에 값을 제한한다. 새 그림은 실제 값을 보존하고 축 범위를 조정하거나 명시한 clipping/범위 밖 표시를 사용한다.

근거 위치는 작업표의 `source_line`과 `source_id_occurrence_lines`에 남겼다. 기준 커밋 이후 소스가 바뀌면 위치를 다시 생성한다.

## 자료·계산 기준

[37개 모듈 자료 기준표](VISUAL_DATA_CONTRACTS_STAGE1_20261104.csv)에 실제 존재하는 변수명·소스 줄과 유지/재생성 방침, 계산 대상, 단위·가정을 기록했다. 변수의 존재를 확인했다는 것이 모든 저장 요약값의 정확성을 검증했다는 뜻은 아니다.

- **원교재:** 개념·학습 맥락·검정 규칙의 근거다. 페이지 캡처나 원문 그림의 배치를 확대·추적해 새 원본으로 쓰지 않는다.
- **기존 모듈 원자료:** 이미 정의된 학습용 자료는 유지하고, 그림·표·본문·실습·문항을 같은 입력에서 계산한다. 교재 수치를 섞어 덮어쓰지 않는다.
- **저장된 요약만 있는 자료:** 생성 설정이 확인되지 않으면 재현 가능한 새 예시로 교체한다. 이전 값에 맞추려고 난수 seed나 도수를 조정하지 않는다.
- **개념도:** 실제 계산 결과로 오인하지 않게 명시한다. t-SNE/UMAP 등 알고리즘 결과로 소개하려면 실제 자료와 설정으로 실행한다.
- **PCA:** `DX`를 기준으로 표준화·점수·기여율을 다시 계산한다. `LOAD`의 변수–주성분 상관과 `WT`의 점수 계수를 구분하고, 반올림된 기존 배열의 사소한 차이를 재계산 결과에 맞춰 정리한다.

### M31 처리 방침 — 재현 가능한 새 사후 표집

**원체인 복구로 간주하지 않고 새 계산을 만든다.** 기존 관측 `GA`/`GB` 각 10개(평균 550/565 MPa)와 꽃 자료 `FX`/`FY`를 유지한다. 사후 요약 배열만 교체하는 데 그치지 않고 trace·도수·EAP·신용구간·꼬리 확률·본문·실습·문항을 같은 생성물에 연결한다.

이표본 사례의 제작 명세:

- 관측 모형은 집단별 독립 정규분포 `y_g ~ Normal(μ_g, σ_g)`로 둔다. 기존 평균 사전 `μ_g ~ Uniform(0,1000 MPa)`를 유지한다.
- 현재 설명에 빠진 표준편차 사전은 새 예시의 선택임을 밝히고 `σ_g ~ HalfNormal(50 MPa)`로 명시한다. 이는 원교재나 기존 체인에서 복구한 조건이 아니다. 제작 시 사전 예측과 척도 민감도를 확인한다.
- `μ`와 `log σ` 좌표의 Metropolis 표집 등 명시된 방법을 사용하며, log σ 변환 시 Jacobian을 반영한다. 5개 서로 다른 초기값·독립 난수 흐름을 저장한다.
- 최초 생성 목표는 체인당 번인 1,000회+보존 5,000회로 두되, 고정 길이 자체를 진단 통과로 삼지 않는다. 제안 폭을 조정한다면 번인 구간에만 적용하고 보존 구간에서는 고정한다.
- seed·난수 생성기·버전·초기값·사전·제안 분포·번인·전체 체인을 저장한다. 표시용 trace 축약본은 전체 체인에서 파생하며 간격·표시 범위를 명시한다.
- rank-normalized split R-hat·bulk/tail ESS와 자기상관을 확인한다. 진단이 나쁘면 실행을 늘리거나 방법을 조정한다. 진단 숫자를 얻기 위해 체인 일부를 골라 버리지 않는다.
- 새 결과가 기존 EAP 14.9, 구간 [4.8,25.5], 꼬리 확률 83.5%와 달라도 새 계산값을 따른다. 기존 값에 강제로 맞추지 않는다.

꽃 사례는 `FX`/`FY`를 유지하되 별도의 푸아송 모형·사전·계산 명세를 작성하고 사후 표집을 재생성한다. 이표본 체인과 표본수를 공유한다고 가정하지 않는다. 기존 `exp(E[a]+E[b]x)`는 계수 사후평균을 대입한 곡선이며 `E[exp(a+bx)|자료]`와 같지 않으므로 라벨을 구분한다. 함수 값을 자르지 않도록 축/clip을 구성한다.

이 결정으로 **자료 처리 방침은 확정됐지만 M31 수치 문제 자체가 해결된 것은 아니다.** 실제 생성·진단·모듈 반영은 2단계 F 시안과 5단계에 걸쳐 완료한다.

## 2단계에서 확인한 사전분포 명세 정정

후속 소스 재확인에서 기존 M31 주석에 `σ Uniform(0,100)`이 적혀 있음을 확인했다. 위 1단계의 HalfNormal(50) 제안은 채택하지 않았다. 2단계에서는 기존 사전 구간을 따르고 공통 σ를 명시해 새 체인을 생성했다. 원체인 복구와는 구분한다. 현재 결과와 완료 범위는 [2단계 기록](VISUAL_STAGE2_REVIEW_20261104.md)을 따른다. 이 문서·작업표는 1단계 기준 소스의 기록이므로 이후 요소 구조가 바뀐 소스에 그대로 재분류하지 않는다. `build_visual_worklist.py`는 기준 목록과 현재 요소가 다르면 파일을 쓰기 전에 중단한다.
