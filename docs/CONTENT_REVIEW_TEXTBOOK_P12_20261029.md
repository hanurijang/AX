## 원문과 보충의 경계

- 계산 재현성과 추시의 구분은 용어 혼동을 줄이기 위한 **이 모듈의 약속**이다. 모든 분야의 번역이 동일하다거나 교재가 이 구분을 그대로 채택했다고 주장하지 않는다. 계산 일치만으로 연구 설계나 추시 성공이 보장되지는 않는다.
- 35/97과 평균 효과크기 약 절반은 교재가 소개한 과거 조사다. 이번에 원논문의 원자료를 새로 분석하거나 현재 학계 전체의 재현성을 추정한 결과가 아니다. 기존 그림의 r=.403·.197도 새로 재산출하지 않았다.
- PUB의 1,000건 히스토그램·공개 건수·평균은 기존 저장 예를 유지했다. 원시 시험 자료가 없어 원래 t검정 1,000회를 재실행하거나 선택된 평균을 새로 검증했다고 주장하지 않는다. 히스토그램 도수 합과 표시 일치 여부를 확인했다.
- 문항 6과 새 선택 보충의 평균 0 주장은 추정 분포와 검정/선택 규칙이 0에 대해 대칭이라는 조건에 의존한다. 방향 선택까지 하는 PUB 예와 다르다. 별도의 표준정규분포 적분 예는 그 대칭성을 설명하는 수학적 확인이다.
- 원문 369쪽의 통계/기계학습과 수리 모형 구분은 설명용 경향이다. 중첩과 외삽 조건을 보충했으며, 냉각+정규 관측오차 예나 검증 후 모형을 바꾸면 추가 평가 자료가 필요하다는 설명이 원문에 그대로 실렸다고 주장하지 않는다.
- 코일 데이터·후기 관측·k=.04h⁻¹은 모듈의 **가상 예**다. 실제 공장의 측정·안전 운전 기준·검증된 물리 상수가 아니다. 일정한 Ta·k, 균일한 내부 온도라는 가정을 사용한다. 100℃ 도달 식은 여기서 T₀>100℃>Ta, k>0인 입력 범위에 적용했다.
- k=.04는 예시의 고정 계수이자 현재 슬라이더 간격에서 Ta=25℃의 최소 SSE 설정이다. 연속 최적화의 최적 k와 같다고 하지 않는다. 작은 적합 오차도 실제 고온 코일이나 새로운 환경의 예측 성능을 보장하지 않는다.
