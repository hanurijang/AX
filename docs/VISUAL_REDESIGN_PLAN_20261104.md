## 3. 제작 공통 기준

### 고해상도와 읽기

- 그래프·도식은 SVG를 원본으로 유지하고, 실습은 같은 계산 함수와 자료에서 갱신한다. 고정 그림으로 교체해 실습 기능을 잃지 않게 한다.
- 수치표·비교표는 복사·검색·스크린리더 이용이 가능한 HTML 표로 작성한다. SVG 안의 작은 수치표는 본문 HTML 표로 옮기는 것을 우선 검토한다. 각 모듈의 기존 HTML 표가 모두 교체 대상은 아니다.
- 현재 960×540 논리 화면과 상단 단계·하단 이동·우측 본문 배치는 유지한다. 그림이 복잡하면 글자를 줄이기보다 화면을 나눈다.
- SVG 내부 눈금·데이터 라벨은 논리 크기 12–14px 이상, 축 제목·범례는 14–16px를 시작 기준으로 삼고 실제 축소 화면에서 판독성을 확인한다. 이 수치는 CSS 실제 표시 크기를 보장하지 않으므로 1280×800과 1920×1080에서 별도 확인한다.
- 공유용 전체 화면은 3840×2160 PNG로 내보낼 수 있게 하고, 원본 SVG도 제공한다. 인쇄용 래스터가 필요하면 사용 크기를 정한 뒤 300dpi로 산정한다. 사진이 필요할 때만 최대 표시 크기의 2배 이상 이미지를 사용한다. SVG에는 DPI 목표를 적용하지 않는다.
- 텍스트 대비는 일반 글자 4.5:1, 큰 글자 3:1, 의미를 전달하는 그래프 요소는 주변과 3:1을 목표로 한다. 색만으로 구분하지 않고 선 종류·기호·직접 라벨을 함께 쓴다.

### 직관적인 구성

한 화면에는 한 질문을 둔다. 기본 흐름은 **자료 → 시각적 비교 → 수치 요약 → 해석**으로 한다. 비교 그림은 축 범위·눈금·표본수를 맞추고, 관련 점·표 행·계산 결과를 같은 기호로 연결한다. 설명에 필요한 축·분모·기준선은 항상 보이게 한다. 장식 인물·배경이 비교 공간을 줄이면 축소한다.

히스토그램은 구간을 명시하고 불균등 구간이면 도수밀도를 사용한다. 막대 길이로 양을 비교하면 0 기준을 쓴다. 점추정·구간 그림에서 축을 좁힐 때는 범위를 분명히 표시한다. 축 절단이 필요한 소득 예시는 전체 범위 요약과 확대 그림을 분리하고, 확대 구간 안에 극단값을 같은 축처럼 끼워 넣지 않는다.

### 정확성과 표현

각 그림은 `원문 개념 / 실제 사용 자료 / 계산식·가정 / 단위 / 출력 수치 / 해석 한계`를 가진다. 자료는 원교재 원자료, 새 학습용 가상 자료, 개념도로 구별한다. 실제 데이터가 없는 개념도에 정밀한 추정치나 실제 알고리즘 결과처럼 보이는 축을 붙이지 않는다.

짧은 설명도 조건과 대상을 남긴다. “표본이 크면 정확해집니다” 대신 “무작위 표본에서는 n이 커질수록 표본평균의 변동이 줄어듭니다”, “두 집단이 같습니다” 대신 “이 자료로는 평균 차이가 있다고 판단하기 어렵습니다”로 쓴다. “핵심을 한눈에”, “놀라운 통찰”, “완벽하게 이해” 같은 추상 문구보다 관찰 결과를 직접 쓴다. 출처 캡션은 `통계101, 통합 PDF126, 그림 5.1.7–5.1.8의 개념을 바탕으로 새로 작성. 자료: 학습용 가상 자료`처럼 개념 출처와 자료 출처를 구분한다. 저자·판본 서지정보는 표제지에서 확인한 뒤 추가한다.

통계 용어·기호의 의미는 앞뒤 모듈에서 통일한다. 빨강=나쁨, 파랑=좋음 같은 가치 판단을 기계적으로 붙이지 않는다. 남녀·질병·성적 사례는 통계적 비교에 필요한 범위만 설명하고 집단의 본질적 차이나 인과관계로 단정하지 않는다. 건강·정책 모형은 학습용 가정의 결과임을 표시한다.

## 5. 먼저 만들 대표 시안 6종

아래 6종은 제작 방식의 기준을 정하기 위한 첫 묶음이다. 현재 요소 ID는 [전체 목록](VISUAL_ASSET_INVENTORY_20261104.csv)에서 찾을 수 있다. 시안은 각각 기본 화면과 입력을 바꾼 화면을 함께 검토한다.

### A. 평균·중앙값과 극단값 — M05 `m5-town`, `m5-box`, `m5-five`

원문 PDF61의 전후 비교와 PDF66의 히스토그램–상자그림 연결을 바탕으로 재작성한다. 현재 소득 그림에는 축 생략 기호와 극단값을 좁은 공간에 함께 배치하고 있다. 새 구성은 ① 전체 범위에서 극단값의 위치 ② 같은 축으로 확대한 기존 주민의 분포 ③ 전후 인원·합계·평균·중앙값 HTML 표로 나눈다. 극단값 때문에 기존 주민의 분포를 읽기 어려운 문제를 확대 그림으로 해결한다.

모듈의 가상 100명 자료를 기준으로 한다. 원자료 배열 하나에서 두 그림과 표를 생성하고, 101번째 값 추가 전후를 재계산한다. 상자그림은 같은 자료를 사용하되 소득 전후 그림과 한 화면에 무리하게 합치지 않는다. 사분위수 계산 규칙·1.5IQR 경계·실제 수염 끝·경계 밖 점을 구분한다. 완료 조건은 도수 합 100/101, 요약값 재계산 일치, 확대 축과 전체 축의 관계가 표시되는 것이다.

### B. 반복 신뢰구간과 오차막대 — M10 `m10-twenty`, `m10-tci` / M13 관련 그림

원문 PDF112·137을 바탕으로 두 장으로 나눈다. 첫 장은 고정된 모평균 기준선과 반복 표집한 구간을 보여 주고, 포함 여부를 색과 기호로 표시한다. “20개면 반드시 19개 포함”처럼 고정하지 않고 실현된 포함 수를 표시한다. 두 번째 장은 같은 자료에 대해 SD·SE·95% t 구간을 **각각 이름을 붙여** 비교한다. SD는 개인들의 퍼짐, SE는 평균 추정의 변동, CI는 추정 절차의 구간이라는 차이를 그림 옆 한 문장으로 쓴다.

M10의 ±2SE는 도입용 근사임을 유지한다. M13의 유의성 판단은 검정 통계량·p값과 연결하고 개별 구간의 겹침으로 대신하지 않는다. 완료 조건은 선택된 표본·자유도로 계산한 끝점 일치, 축 밖 구간의 숨김 없는 표시, 반복 표집과 고정 표본의 해석 분리다.

### C. 회귀선·잔차·두 구간 — M18 `m18-ls`, `m18-band`, `m18-p3-svg`

원문 PDF196의 모형·계수 설명을 바탕으로 한 산점도를 공통으로 쓴다. ① 관측점과 적합선 ② 각 관측 x에서 적합선까지의 수직 잔차 ③ 평균 반응의 점별 95% 신뢰구간 ④ 새 관측 하나의 95% 예측구간 순서로 드러낸다. 구간은 직접 라벨과 채움/경계선으로 구별한다. 평균 구간과 예측구간은 별도 표시 선택도 제공한다.

범례에는 “이 x에서의 평균”과 “이 x의 새 관측 1개”를 쓴다. 표시 영역을 벗어난 선은 수학 값을 바꾸지 않고 clip 처리하고, 관측 범위 밖은 배경·점선으로 구별한다. 완료 조건은 OLS 독립 계산과 계수·잔차제곱합·두 구간 일치, 같은 x에서 예측구간이 평균 구간보다 좁지 않음, 기존 27차 좌표 검사 통과다.

### D. 관측 차이와 인과효과 — M28 DAG / M29 매칭·DID

원문 PDF294·307의 질문을 바탕으로 개념 DAG와 수치 예시를 나눈다. 먼저 공통원인에서 두 변수로 화살표가 나가는 그림에 “가정한 인과구조”를 표시한다. 그 다음 관측 산점도와 개입 모형 결과를 나란히 놓는다. 알 수 없는 효과는 `?`로, 모형에서 0으로 정한 효과는 `0 — 이 예시의 가정`으로 표시한다.

DID는 실제 전후 관측을 실선, 평행추세 아래의 반사실을 점선으로 표시하고 두 차이의 차이를 괄호로 계산한다. 매칭은 장식적인 사람 연결보다 처리 전 공변량의 균형도와 공통지지 구간을 우선 보여 준다. 완료 조건은 관측/가정/반사실의 구별, ATE·ATT의 대상 일치, 표시 수치에서 DID 재계산, 인과 식별 조건의 누락 없음이다.

### E. 주성분 결과를 읽는 표와 그림 — M32 `m32-axis`, `m32-cont`, `m32-load`

원문 PDF344는 기여율·주성분 부하량·점수라는 서로 다른 표를 제시한다. 현재 제조 예시도 이 구별을 유지하면서 ① 표준화한 원변수 ② PC 축과 투영 ③ 기여율 막대 ④ 부하량 HTML 표와 점수 산점도로 나눈다. 현재 `m32-load`의 작은 수치 셀은 읽기 쉬운 표로 옮기고 선택한 시편 행과 산점도의 점을 함께 강조한다.

부하량을 변수–주성분 상관으로 정의했다면 고유벡터 계수와 혼용하지 않는다. 주성분 부호를 바꾸면 표·축·해설을 함께 바꾼다. 완료 조건은 표준화 방법·고유값·기여율 합·점수 계산 일치, 단위 변경에 따른 공분산 PCA와 상관 PCA 차이 재현이다.

### F. MCMC의 결과와 믿을 근거 — M31 `m31-trace`, `m31-diff`, `m31-p3-svg`

원문 PDF326·333의 MCMC와 사후 추정을 바탕으로, 실제 저장된 체인에서만 trace와 사후 히스토그램을 만든다. “여러 선이 모여 보인다”는 그림만으로 수렴을 보장하지 않는다. 초기 제외 구간, 체인별 잔류 표본수, 자기상관·ESS·R-hat, 추정 대상과 구간 정의를 함께 제시한다. 진단 지표도 완전한 수렴의 증명이 아니라는 한계를 적는다.

원체인이 없으면 새 가상 예시를 재현 가능하게 생성해 점그림·사후분포·수치표·실습·문항을 모두 갱신한다. 현재 도수의 누락 1건은 새 생성 자료로 교체할 때까지 미해결로 남긴다. 완료 조건은 체인 저장·설정 재실행 가능, 도수 합=포함된 표본수, 경계 밖 표본의 처리 공개, 사후 요약값 독립 계산 일치다.

| PCA·평가 지표 | 표 제목에서 점수/부하량/계수 구별, 혼동행렬은 실제/예측 방향 고정 | 산점도/ROC 등 관련 그림과 같은 계산 결과 사용 |

HTML 표에는 `caption`, `th`, `scope`를 사용한다. 수치는 소수 자릿수와 단위를 맞추고 숫자 정렬을 통일한다. p값을 `0.000`으로 표기하지 않으며, 비유의 결과를 숨기거나 유의한 칸만 과도하게 강조하지 않는다. 셀을 색칠할 때는 숫자·부호·범례를 함께 제공한다. 행이 많으면 의미 있는 범위로 나누고 전체 자료를 별도 제공한다.

## 7. 작업 순서와 산출물

| 단계 | 작업 | 산출물·다음 단계 조건 |

제작량·기간은 1단계에서 고유 그림군과 재사용률을 확정한 뒤 산정한다. 722개를 전부 다른 그림으로 세어 일괄 제작량이나 완료일을 약속하지 않는다. 공통 축·범례·표 스타일은 공유하되 서로 다른 통계 개념을 같은 템플릿에 억지로 맞추지 않는다.

그림 1건의 작업표는 다음 정보를 갖는다.

`모듈 / 슬라이드 ID 또는 소스 순번 / 요소 ID 또는 순번 / 원문 통합 쪽·그림번호 / 학습 질문 / 현 상태의 근거 / 유지·통일·분할·재작성 / 자료 종류·파일·seed / 계산식·가정 / 새 구성 / 본문·문항 영향 / 수치 검증 / 화면 검증 / 검토 상태`

이번 계획 작성에서 실시한 것은 전체 소스 요소 목록 작성, 원문 대표 쪽 이미지 확인, 기존 검수 기록 대조다. 아래는 **향후 제작물의 검사 기준**이며 이번에 모두 실행·통과했다는 뜻이 아니다.
