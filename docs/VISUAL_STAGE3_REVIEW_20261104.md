## 읽기·저장 기능

하단 **그림·표 크게 보기**에서 현재 화면의 그림이나 표를 선택할 수 있다. 그림은 현재 실습 상태의 정적 복사본으로 보여 주며 배율은 100~250%다. 확대창에서 원래 슬라이드의 버튼이나 입력을 대신 조작하지 않는다.

- SVG는 벡터로 저장한다. 색·글자·선 스타일과 내부 마커/참조 ID를 복사해 독립 파일로 만든다.
- PNG는 원래 종횡비를 유지하며 긴 변을 3,840픽셀로 저장한다. [실제 다운로드 SVG](visual-stage3-previews/m01-export.svg), [PNG](visual-stage3-previews/m01-export.png).
- HTML 표는 제목·행·열 머리글과 값을 크게 읽고 복사할 수 있다. 표를 그림으로 굳히지 않았다.
- 확대창은 Tab/Shift+Tab 초점을 내부에 유지하고, Escape로 닫은 뒤 열었던 버튼으로 돌아간다. 방향키·PageUp/Down이 뒤쪽 슬라이드를 넘기지 않도록 분리했다.
- 복사본에서는 원래 SVG 안의 상호작용 버튼 역할을 제거한다. 원본 그림의 버튼과 이벤트는 유지한다.
- 공통 도구는 각 HTML 안에 포함돼 별도 서버 API나 외부 스크립트가 필요 없다. 원본은 `scripts/templates/visual-tools-stage3.*`, 재적용은 `scripts/apply_visual_tools_stage3.py`다. 두 번 적용해도 16개 파일이 변하지 않는 것을 확인했다.

## 정확성과 표현에서 정리한 점

**비율을 왜곡하던 최소 막대 너비:** M03은 매우 작은 비용에도 최소 2픽셀 막대를 주면서 실제 비율이라고 설명하던 구성을 정확한 수치표로 교체했다. 조사 대상 5천만 명×100원은 50억 원이므로 본문의 “50억 원이 넘는다”도 “50억 원이다”로 맞췄다.

**분산의 분모와 도식의 의미:** M05의 9개 점수에서는 기술통계 SD의 분모 n을, M12·M13에서는 표본 SD의 n−1을 구별한다. M05 바이올린은 대역폭 5점인 상대 밀도이며 대역폭에 따라 모양이 달라진다고 명시한다. 수염의 한계 23.5/99.5와 실제 수염 끝 45/74도 구별한다.

**구간·p값·다중비교:** M10은 기존 고정 20개 구간을 나누어 보여 주되, 실제 포함 수를 계산하고 특정 포함률이 보장되는 듯한 표현을 피했다. M11은 관측 차이의 절댓값 이상인 순열 70/3432로 양측 p를 표시한다. M13 평균±SE는 95% CI와 구분한다. M15 구간은 각 집단 평균의 구간이 아닌 세 쌍 평균차의 동시 구간이다. Tukey 표의 반올림 값은 SciPy 독립 계산과 대조했다.

**대응·독립 자료와 기대도수:** M14의 행은 신약군의 같은 환자 ID를 따른다. 별도 위약군을 옆 열에 같은 환자처럼 놓지 않았다. M16은 관측/기대 표를 분리하고 행·열 합을 함께 표시하며 사용한 검정 방법을 밝힌다. Fisher의 칸은 χ²를 사용하지 않는다는 뜻으로 표시했다.
