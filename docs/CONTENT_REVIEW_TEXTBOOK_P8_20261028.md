## 원문과 보충 설명의 경계

- M13의 개별 구간 겹침 반례는 **독립 정규 평균 추정값 10·13, 알려진 SE가 각각 1인 별도 모형**이다. 기존 신약·위약 7명 자료나 교재의 SE 경험칙을 재계산한 그림이 아니다. 각 평균의 구간은 10±1.96과 13±1.96이며, 차이 구간은 3±1.96√2다.
- α 이하의 오류율, 이산형의 보수성, 검정 설계를 고정한 표본수 계산과 작은 표본 t검정의 근사 한계는 원문을 엄밀화한 보충이다. 정상적인 p값의 조건을 전제로 하며, 모든 사후 방법 선택에 오류율 통제가 그대로 유지된다는 뜻은 아니다.
- M16의 70/100 대 90/150, 희소 표 [[4,6],[0,10]]은 **새 가상 보충 예제**다. 원문 사슴벌레 자료를 변경한 결과가 아니다. Fisher는 주변합에 조건을 둔 양측 확률질량 합을 사용하며 다른 검정과 같은 수치가 나와야 하는 것은 아니다. 더 큰 표의 정확법·모의검정을 실제 실행한 것은 아니다.
- 교재 173쪽은 관측·기대 편차를 그대로 쓴 식 옆에 χ²=4.33을 제시한다. 현행에 이미 있던 무보정 5.66과 보정 4.33의 구별을 유지하고 독립 계산으로 확인했다. 이번에 교재의 식을 그대로 복제하지 않았다.
- M17의 단조/비단조 구분, 일정한 열의 미정의, 기술 계산과 정규 추론의 구분, 공통 분모 해석은 엄밀화한 보충이다. 두 주변분포의 정규성 검사만으로 이변량 정규성이나 독립 표집이 증명되지 않는다.
- M17의 저장 이상점 자료는 모듈 자체 예제다. 원문 186쪽에 소개된 순위상관 수치를 억지로 대입하지 않고 저장 배열을 재계산했다. 새 현장 자료 수집·인과효과 추정·상호정보량 산출을 수행한 것으로 해석하지 않는다.
