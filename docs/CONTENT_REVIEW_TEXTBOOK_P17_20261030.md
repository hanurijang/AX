## 실제 수정과 독립 확인 기준

- **M01:** 평균이 극단값의 영향을 받지 않는다는 듯한 해설을 정정했다. 고정 n=12에서 한 관측값을 Δ 바꾸면 평균 변화는 Δ/12다. 평균만으로 개별 극단값을 식별할 수 없다는 설명은 유지한다.
- **M03 화면:** 실습 3의 예시 답을 펼치면 본문이 5px 넘쳤다. 해당 피드백의 기본 문단 여백을 정리하고 내용은 유지했다.
- **M04:** 이미 본문·문항에서 구별하던 히스토그램/범주형 막대그래프를 목표·실습 질문에도 반영했다. 분류 카드나 분포 자료를 변경하지 않았다.
- **M05:** 기술용 SDₙ=√[Σ(x−x̄)²/n]를 절대편차의 평균과 구별한다. 고정 평균 60·SD 10의 2SD 점검은 ≤40/≥80, 본문 Q1=52·Q3=71의 IQR 경계는 23.5~99.5다. 36·85는 앞의 점검 대상이면서 뒤의 IQR 이상값은 아니다. 어느 기준도 자동 삭제 근거로 제시하지 않는다.
- **M06:** 구슬 r,w에서 확률과 E를 계산하고, 같은 분포의 V=Σ(금액−E)²P를 새로 표시한다. 4·1은 E=180원·V=25,600원²·SD=160원이며 8·2에서도 같다. 0·0은 정의되지 않아 확률·기댓값·분산을 모두 ‘-’로 초기화한다. 한 색만 있으면 분산은 0이다. 독립 계산은 `E(X²)−E(X)²`를 유리수로 구해 대조한다.
- **M06 조건부확률:** 표지 구슬 5개의 가능한 비복원 순서쌍 20개를 열거한다. 첫째가 붉은 조건의 16개 중 둘째가 흰 경우는 4개여서 1/4다. 조건을 모를 때의 1/5 및 복원 독립 모형의 1/5와 구별한다. 이 구슬 예는 교재의 옷 조합 예에 같은 개념을 적용한 보충이다.
- **M07:** z 모드 −3~3(0.1 간격), 가상 T 모드 20~80(1 간격)을 선택한다. T를 z=(T−50)/10으로 되돌려 원래 키 공간의 예측 위치를 그린다. 피드백 판정은 z 차이 ≤0.2로 두 척도에서 같다. 답 확인 후 예측 변경·척도 전환·다음 사람에서 기존 결과를 지우며, 새 사람/척도는 중립 예측 z=0 또는 T=50으로 시작한다. 기존의 서로 다른 분포에서 z 크기만으로 꼬리를 비교할 수 없다는 조건을 유지한다.

원문의 가상 키·점수·구슬 예와 모듈 보충의 구별을 유지했다. T=50+10z는 이 실습의 환산 약속이며 실제 수능 공식이나 모든 표준점수 정의가 아니다. 과거 문서의 외부 URL 확인 날짜는 갱신하지 않았다.
