## 원문과 보충의 경계

- 조건부 계수·중심화, VIF 경고선의 한계, 선택 후 추론과 정칙조건 등은 원문 도입을 엄밀화한 보충이다. 원문에 그대로 실린 문장이라고 주장하지 않는다. 원문과 현행 모듈이 이미 올바른 부분은 유지했다.
- M20의 새 중심화 예는 기존 2×2 가상 자료의 재표현이다. 새 실험이나 인과효과 추정이 아니다. 원래 상호작용 기울기의 오류를 고쳤다고 기록하지 않는다.
- M21의 OR=2 예는 수학적 환산이다. 실제 약효·발병 위험을 새로 추정한 것이 아니다. 사례-대조 OR의 성질은 적절한 표집 조건에 의존하며 절대위험에는 추가 정보가 필요하다.
- M23의 AICc 식은 독립·정규·등분산 오차의 최대가능도 회귀에 쓰는 표준식이다. 모든 GLM·의존 자료·베이즈 모형에 일괄 적용하지 않는다.
- M20의 반복 계수 배열 150개씩, M23의 부트스트랩 1,000개·선택 비율 SEL·새 자료 MSE는 기존 저장 예를 유지했다. 계수 배열의 SD·부트스트랩 분위수는 재계산했지만 원래 모의실험 전체를 다시 실행하지 않았다. MSE의 새 검증 원자료는 모듈에 없으므로 독립적으로 재평가했다고 주장하지 않는다.
