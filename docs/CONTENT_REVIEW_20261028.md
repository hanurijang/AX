## 수치 근거

두 독립집단의 공통 분산을 가정하고, nA=nB=17, 평균 A=500, B=509 MPa, 표본표준편차 sA=10.2, sB=9.6 MPa로 계산했다.

- sₚ = √[(16×10.2² + 16×9.6²)/32] = 9.9045444115 MPa
- d = (509−500)/sₚ = 0.9086737992
- df = 32, J 근사 = 1−3/(4×32−1) = 0.9763779528
- g 근사 = J×d = 0.8872090638
- t = 9/[sₚ√(1/17+1/17)] = 2.6492166057
- 양측 p = 2×t₃₂ 생존함수(|t|) = 0.0124280948 (`scipy.stats.t.sf`로 독립 계산)

J는 가이드에 제시된 근사식이다. 집단 순서를 바꾸면 d와 g의 부호만 바뀐다. 두 집단의 n이 같아 통합표준편차의 반올림 값은 기존과 같지만, 기존의 일반 공식은 바로잡아야 한다.
