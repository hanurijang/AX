# M31 재현 가능한 학습용 사후 표집

이 자료는 기존 관측값을 사용한 **새 계산**이다. 이전의 도수 24,999개를 보정하거나 원체인을 복구한 자료가 아니다.

- 생성: `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python scripts/generate_m31_visual_data.py`
- 검증: `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python scripts/review_visual_stage2.py`
- NumPy·SciPy 버전, 입력값, 모형, 제안 분포, 수용률, 진단, 원파일 SHA-256은 `m31_summary.json`에 기록한다. 기록된 버전의 같은 환경에서 다시 생성했을 때 세 생성물의 해시가 일치했다.

## 파일 형식

| 파일 | 내용 |
|---|---|
| `m31_normal_chains.json.gz` | gzip 압축 JSON. `columns=[muA,muB,sigma]`, `chains` 크기 5×6001×3. 평균과 공통 표준편차의 단위는 MPa |
| `m31_poisson_chains.json.gz` | gzip 압축 JSON. `columns=[a,b]`, `chains` 크기 5×6001×2. 원래 x 척도에서의 절편과 기울기 |
| `m31_summary.json` | 입력값·모형·생성 설정·진단·등꼬리 구간·히스토그램·10회마다 뽑은 표시용 trace·파일 해시 |

각 체인의 인덱스 0은 초기 상태, 1~1000은 번인, **1001~6000은 보존 표집**이다. 체인당 5,000개, 모형마다 총 25,000개를 보존한다. 반올림하지 않은 전체 체인으로 모든 통계량을 계산한다. 표시용 trace는 10회 간격이며, 번인 이후 그림은 이 중 1010회부터 표시한다. 진단에는 1001회부터의 보존 표집을 모두 사용한다.

## 모형과 표집

정규모형은 집단별 평균 μA·μB, **공통 σ**를 사용한다. 평균 사전은 각각 Uniform(0,1000), σ는 Uniform(0,100)이다. 소스 주석에 있던 사전 구간을 따르고, 분산을 공유한다는 조건을 이번 계산과 화면에서 명시했다. 기존 원체인의 세부 구현이 복원됐다는 의미는 아니다.

평균은 조건부 절단정규분포에서 깁스 표집하고 log σ는 무작위 보행 메트로폴리스 방법으로 갱신한다. log σ의 Jacobian을 반영한다. 푸아송모형은 `y ~ Poisson(exp(a+b*x))`, 사전은 a에 Uniform(−10,10), b에 Uniform(−5,5)다. 중심화·척도 조정한 x 좌표에서 두 계수를 함께 갱신한 뒤 원래 척도로 되돌린다.

두 모형은 독립적인 난수 흐름 `SeedSequence([20261104,1])`, `SeedSequence([20261104,2])`와 PCG64를 사용한다. 제안 폭 조정은 번인에만 적용하고 이후에는 고정한다. 초기값·최종 제안 폭과 수용률을 함께 보존한다. seed를 결과에 맞춰 고르지 않았다.

## 검증 범위

- 히스토그램에 전체 보존 표집 25,000개가 들어가는지, 분위수·기댓값·임계값별 확률이 같은 원자료에서 나오는지 확인한다.
- rank-normalized/folded split R-hat, bulk/tail ESS를 계산한다. ESS 계산은 AR(1), ρ=0.8에서 이론적 규모와 대조하고 체인별 평균이 다른 예시도 확인한다.
- 정규모형은 평균을 적분한 공통 σ의 사후분포로 별도 수치 적분한다. μ의 매우 먼 경계에 의한 절단 효과는 이 자료·범위에서 부동소수점 정밀도보다 작다.
- 푸아송모형은 별도 2차원 격자 적분의 평균·분위수와 대조한다. 격자 끝에서의 질량과 표집 오차를 함께 확인한다.

진단 통과는 모든 모드 탐색이나 모형의 현실 타당성을 증명하지 않는다. MCMC 기댓값·구간은 몬테카를로 오차가 있고 독립 수치 적분값과 정확히 같을 필요는 없다. 푸아송 그림의 곡선은 `exp(E[a]+E[b]x)`이며 사후 예측평균 `E[exp(a+bx)]`과 구분한다.
