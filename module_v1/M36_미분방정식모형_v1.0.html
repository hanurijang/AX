4-1 차분 방정식과 지수함수 증가 · 기초

Q5일마다 2배로 늘어나는 규칙은 어떻게 쓸까요?

핵심 수학 개념 · 차분 방정식과 그 해
x(t+1) = 2x(t), x(0) = 1 → x(t) = 2t
기호t: 5일 단위 시각(이산 시간), x(t): 시각 t의 감염자 수
계산50일 → t = 10 → 210 = 1,024명
  • 차분 방정식: 다음 값 = 규칙(지금 값)
  • 지수함수 증가: 2t처럼 급격히 늘어남

시간을 5일 단위 t = 0, 1, 2…로 띄엄띄엄 보고 감염자 수를 x(t)라 하면, 5일 뒤 수는 지금의 2배라는 증가 규칙을 식으로 쓸 수 있습니다. 차분 방정식을 푼다는 것은 x(t)를 t의 함수로 나타내는 것으로, 초항 1·공비 2인 등비수열이므로 x(t) = 2t입니다. 50일 뒤에는 1,024명으로 직원 수를 넘습니다.

다음 질문배율이 2가 아니라면?

4-1 차분 방정식과 지수함수 증가 · 기초

Q배율 r을 바꾸면 움직임은 어떻게 달라질까요?

  • r > 1 증가, r = 1 유지, r < 1 감소(0까지)
  • 분기 다이어그램: r = 1이 질적 경계

일반적으로 파라미터 r을 써서 x(t+1) = r·x(t)로 나타내면 해는 x(t) = x(0)·rt입니다. r이 1보다 크면 정량적으로는 달라도 지수적으로 늘어난다는 점에서 같고, r이 딱 1이면 변하지 않으며, 1보다 작으면 지수적으로 감소합니다. 파라미터 r을 가로축, 충분한 시간이 흐른 뒤의 값을 세로축에 두면 r = 1을 경계로 질적으로 다른 움직임이 한눈에 보입니다. 이처럼 파라미터를 다양하게 바꿨을 때 무슨 일이 일어나는지 조사할 수 있다는 것이 수리 모형의 강점입니다.

다음 질문시간을 연속으로 보면?

4-2 미분 방정식과 밀도 효과 · 기초

Q시간 간격을 아주 작게 하면 규칙은 어떻게 쓸까요?

핵심 수학 개념 · 선형 미분 방정식
dx/dt = ax → x(t) = x(0)eat
기호dx/dt: 아주 짧은 시간의 변화율, a: 증가율 파라미터
계산5일마다 2배 → a = ln2 ÷ 5 ≈ 0.139/일
  • 미분 방정식: 연속 시간의 변화율 규칙
  • a > 0 증가, a = 0 경계, a < 0 감소

차분 방정식의 시간 간격을 작게 하면 연속 시간 모형인 미분 방정식을 얻습니다. dx/dt = ax는 가장 단순한 선형 미분 방정식이라 해를 간단히 구할 수 있습니다. 지수적 증가·감소라는 성질은 같지만, 변화율을 나타내므로 경계는 a = 0이 됩니다. 사업장 초기 감염의 a는 약 0.139/일입니다.

다음 질문지수 증가는 언제까지 계속될까?

4-2 미분 방정식과 밀도 효과 · 기초

Q지수적 증가가 끝없이 이어지는 것이 현실적일까요?

  • 밀도 효과: 늘수록 증가율이 줄어듦
  • 로지스틱 방정식: K에서 포화

x(t+1) = 2x(t)나 dx/dt = ax는 모두 x의 상수배로 나타낸 선형 방정식이고, 지수적 증가와 감소는 그 전형적인 움직임입니다. 그러나 지수적 증가가 언제까지나 계속되는 것은 현실적이지 않으므로, x가 늘어날수록 증가율이 줄어드는 밀도 효과를 넣는 것이 자연스럽습니다. 흔히 쓰는 로지스틱 방정식 dx/dt = ax(1 − x/K)는 x가 환경 수용력 K에 가까울수록 증가율을 0에 가깝게 합니다. 닫힌 집단에서 회복 없이 무작위 접촉으로 전파되는 단순 SI 모형이라면 누적 감염자를 로지스틱 식으로 나타낼 수 있습니다. 이때 K = 직원 1,000명입니다. 실제 누적 감염이 항상 이 식을 따르는 것은 아닙니다.

다음 질문K에 도달하면 무슨 일이 생길까?

4-2 평형점 · 추가 읽기

Q더 변하지 않는 상태는 어디이고, 그곳은 안정할까요?

  • x = K는 안정평형점, x = 0은 불안정평형점
  • 비선형 방정식은 상태에 따라 규칙이 변함

여기서는 a > 0, K > 0을 가정합니다. dx/dt = 0을 만족하는 x가 평형점입니다. x가 K보다 크면 dx/dt < 0, 작으면 dx/dt > 0이 되어 x = K로 되돌아가므로 안정평형점입니다. x = 0에서는 조금만 커져도 늘어나기 시작하므로 불안정평형점입니다. 로지스틱 방정식은 x × x의 곱이 있는 비선형 방정식이지만, dx/dt = ax(1 − x/K)는 초기값 x(0) = x₀ > 0일 때 x(t) = K / (1 + (K/x₀ − 1)e^(−at))라는 해석해가 있습니다. SIR처럼 식으로 풀기 어려운 모형은 수치 계산으로 조사합니다.

다음 질문감염병은 어떻게 모형으로 만들까?

4-3 감염병 모형 · 기초

Q감염되고 회복하는 흐름은 어떻게 식으로 쓸까요?

핵심 수학 개념 · SIR 모형
dS/dt = −βSI/N, dI/dt = βSI/N − γI, dR/dt = γI
기호t: 일, β: 전파율(/일), γ: 감염 상태 이탈률(/일)
N = S + I + R = 1,000명 (닫힌 집단)
계산β 0.34, γ 0.2 → 정점 약 100명, 최종 약 692명
  • SIR 모형: S → I → R의 이동
  • S × I 항이 있어 비선형 미분 방정식

이 모형에서 β는 접촉과 감염 가능성을 합친 전파율(/일)입니다. 감수성 보유자 한 명의 감염 위험률은 βI/N이고, 감염자는 이탈률 γ(/일)로 R로 옮겨갑니다. R은 회복·격리 등으로 더 이상 전파하지 않는 집단입니다[1]. 새 감염은 S와 I의 무작위 접촉에 비례한다고 가정하므로 βSI/N 항을 씁니다. 출생·유입·유출이 없어 S + I + R은 일정합니다. 감염자는 처음에 지수적으로 늘다가 S가 줄면서 감소하고, 모두가 걸리기 전에 유행이 끝납니다.

다음 질문유행이 시작될지는 무엇이 정할까?

4-3 감염병 모형 · 기초

Q감염자 한 명이 유행으로 번질지는 무엇으로 알 수 있을까요?

  • 기초감염재생산수 R₀ = β/γ
  • 초기 S(0)/N ≈ 1이고 R₀ > 1이면 유행

기초감염재생산수 R₀ = β/γ는 거의 모두가 감수성 보유자일 때 감염자 1명이 감염시키는 사람 수의 평균입니다. 감염이 진행되면 감수성 보유자가 줄므로, 그때의 값은 실질감염재생산수 Rₜ = (β/γ) × S(t)/N입니다. 초기에 S(0)/N ≈ 1이면 두 값이 거의 같고, dI/dt > 0인 조건도 R₀ > 1과 같습니다. 이 사업장은 0.34 ÷ 0.2 = 1.7로 1을 넘으며, 최종적으로 약 69%가 감염을 겪습니다.

다음 질문대책을 쓰면 어떻게 달라질까?

4-4 예측과 통제 · 기초

Q30일째에 대책을 쓰면 유행은 어떻게 달라질까요?

  • 실질감염재생산수 Rₜ를 1 아래로
  • 예측은 규칙이 그대로라는 전제 아래서만

데이터로 파라미터를 추정하면 앞날을 예측할 수 있지만, 지금까지의 규칙이 달라지지 않는다는 전제의 예측입니다. 유행이 시작된 뒤 면역이나 대책이 반영된 값이 실질감염재생산수 Rₜ이며, 1보다 크면 감염자가 늘어납니다. 접촉을 줄이는 대책은 β를, 조기 격리는 γ를 바꿉니다. 30일째 Rₜ 1.48에서 교대·휴게를 분산해 접촉을 절반으로 줄이면 Rₜ는 0.74가 되어 최종 감염이 692명에서 236명으로 줄어듭니다. 데이터에 없는 조건을 식의 파라미터로 넣어 비교할 수 있다는 것이, 메커니즘을 식으로 둔 모형의 강점입니다.

다음 질문이 모형을 더 좋게 만들려면?

4-4 가정 확장 · 추가 읽기

QSIR 모형의 가정을 바꾸면 무엇을 더 알 수 있을까요?

  • 단순한 SIR도 유행을 잘 기술함
  • 가정을 바꿔 현실 요소를 더함

현상을 적절하게 나타내는 좋은 모형일수록 예측과 통제에 뛰어나며, SIR 모형은 매우 간단하면서도 감염병의 유행을 제대로 기술할 수 있다고 알려져 있습니다. 더 좋은 모형을 얻으려면 가정을 바꾸고 현실적인 요소를 도입합니다. 사람이 모두 동질하다는 가정 대신 연령에 따라 감염률·회복률이 다른 구조를, 접촉 상대가 무작위라는 가정 대신 사회 네트워크 구조를 넣을 수 있습니다. 사업장이라면 교대조·부서별 접촉 구조나 백신 접종 효과를 넣어 대책을 더 정밀하게 비교할 수 있습니다.
