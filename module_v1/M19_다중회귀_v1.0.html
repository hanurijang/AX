학습개요

설명변수를 늘리고 범주형도 넣어, 회귀로 더 많은 것을 설명합니다

지난 모듈에서는설명변수가 1개인 단순선형회귀 y = a + bx + ε를 최소제곱법으로 구하고 결정계수와 오차의 가정으로 평가했습니다.이번 모듈에서는설명변수를 여러 개로 늘린 다중회귀, 범주형 설명변수를 넣는 가변수, 그리고 이를 결합한 공분산분석을 배웁니다.

학습개요 · 이 모듈의 예시

성인 20명의 몸무게를 키, 허리둘레, 운동 여부로 설명합니다

  • 반응변수 1개, 설명변수 3개를 씁니다.

성인 20명의 몸무게(kg)를 반응변수로, 키(cm)와 허리둘레(cm)라는 양적 변수와 평소 운동을 하는지라는 범주형 변수를 설명변수로 씁니다(예시값). 키가 클수록, 허리가 굵을수록 몸무게도 많이 나가는 경향이 예상되며, 운동 여부에 따른 차이도 함께 따져 봅니다.

4-1 선형회귀의 확장

Q단순선형회귀는 어떤 방향으로 넓힐 수 있을까요?

  • 설명변수 · 반응변수 · 모형 형태의 3방향
  • 반응변수를 넓히면 일반화선형모형

실제 데이터에서는 설명변수가 여러 개이거나, 반응변수가 양적 변수가 아니라 예/아니요 같은 범주형 변수일 때도 있어 y = a + bx + ε(ε는 정규분포를 따르는 오차)가 항상 적절하지는 않습니다. 그래서 설명변수의 개수를 늘리거나 유형을 바꾸기, 반응변수의 오차 분포를 이항분포나 푸아송 분포로 바꾸는 일반화선형모형, 상호작용이나 비선형처럼 회귀모형의 형태를 바꾸기의 3가지 방향으로 원리를 넓힙니다.

다음 질문설명변수가 여러 개면 어떻게 쓸까?

4-2 다중회귀와 편회귀계수

Q설명변수가 여러 개이면 회귀식은 어떻게 될까요?

핵심 수학 개념 · 다중선형회귀모형
y = a + b₁x₁ + b₂x₂ + … + bₖxₖ + ε
기호k: 설명변수 개수, b₁ … bₖ: 편회귀계수
계산몸무게 = −66.8 + 0.538 × 키 + 0.535 × 허리
  • 다중회귀: 설명변수가 여러 개인 회귀
  • 각 기울기는 편회귀계수입니다.

설명변수가 여러 개인 회귀를 다중회귀라 하며, 가장 단순한 다중선형회귀모형은 a, b₁, …, bₖ 등 k + 1개의 파라미터를 가집니다. 키와 허리를 함께 고려하면 몸무게를 더 잘 설명할 수 있습니다. b₁은 x₂를 고정하고 x₁을 1 늘렸을 때 y의 증가량이며, 이를 편회귀계수라 합니다. 최소제곱법으로 구하며, 설명변수가 2개이면 회귀모형은 직선이 아닌 회귀평면이 됩니다.

다음 질문다중회귀 결과는 어떻게 읽을까?

4-2 다중회귀와 편회귀계수

Q다중회귀 결과표에서는 무엇을 봐야 할까요?

  • 편회귀계수와 그 유의성을 봅니다.
  • F의 p값: 모형 전체의 설명력이 유의한가

다중회귀 결과는 표로 제시하는 일이 많습니다. 먼저 추정된 편회귀계수와 그 유의성을 봅니다. 키 0.538, 허리 0.535 모두 p < 0.001로 유의하며, 괄호 안 숫자는 추정값의 표준오차로 작을수록 정확합니다. 다음으로 데이터에 잘 들어맞는지를 나타내는 R² = 0.87과, 편회귀계수가 모두 0인 모형을 귀무가설로 한 F통계량의 p값을 봅니다. F = 54.5, p < 0.001이므로 회귀모형의 설명력에 유의성이 있습니다.

다음 질문두 계수의 크기를 비교해도 될까?

4-2 다중회귀와 편회귀계수

Q편회귀계수끼리 크기를 비교해도 될까요?

핵심 수학 개념 · 표준화
zᵢ = (xᵢ − x̄) ÷ s
계산키 0.538 × 8.03 ≈ 4.32, 허리 0.535 × 5.68 ≈ 3.04
해석1 표준편차당 키가 허리보다 기여가 큽니다.
  • 편회귀계수는 단위와 퍼짐에 따라 달라집니다.
  • 표준화편회귀계수로 비교합니다.

편회귀계수는 설명변수의 퍼짐 정도나 단위에 따라 크게 달라지므로 그대로 비교할 수 없습니다. 키를 cm 대신 m로 쓰면 계수는 0.538에서 53.8로 100배가 됩니다. 그래서 회귀분석 전에 각 설명변수를 평균 0, 표준편차 1로 변환한 뒤 구한 표준화편회귀계수를 씁니다. 각 설명변수가 1 표준편차 늘 때의 증가량이므로 비교할 수 있으며, R²나 p값은 원래 결과와 같습니다.

다음 질문설명변수끼리 상관이 있으면?

4-2 다중회귀와 편회귀계수

Q설명변수끼리 상관이 있으면 계수는 어떻게 해석할까요?

  • 편회귀계수는 다른 변수를 고정한 영향
  • 단순회귀 기울기에는 다른 변수 영향이 섞임

설명변수 사이에 상관이 있으면 x₁만 독립적으로 움직일 수는 없고, 상관이 있는 다른 변수도 함께 움직입니다. 이 데이터에서 키와 허리의 상관은 r = 0.49입니다. 키만 넣은 단순회귀의 기울기는 0.724로, 키가 직접 주는 영향에 허리를 통한 영향까지 섞여 있습니다. 허리를 함께 넣은 다중회귀의 0.538은 허리와의 상관을 제외한 키의 영향입니다. 상관이 1에 가까울 만큼 강하면 다중공선성을 의심해야 합니다.

다음 질문범주형 변수는 어떻게 넣을까?

4-3 범주형 설명변수

Q운동 여부 같은 범주형 변수는 어떻게 회귀에 넣을까요?

  • 가변수: 범주를 0 또는 1로 나타낸 변수
  • 기울기 b = 두 범주의 평균 차이

범주에는 대소 관계가 없으므로 회귀분석의 설명변수로 쓸 때는 0 또는 1과 같은 가변수를 씁니다. ‘운동 안 함’을 0, ‘운동 함’을 1로 하면, x = 0인 범주는 y = a + ε, x = 1인 범주는 y = a + b + ε가 되어 기울기 b가 두 범주의 차이를 나타냅니다. 이 데이터에서 b = −4.58kg, p = 0.14로 이표본 t검정의 결과와 일치합니다. 해석할 때는 어느 쪽이 0이고 1인지 꼭 확인합니다.

다음 질문범주가 3개 이상이면?

4-3 범주형 설명변수

Q혈액형처럼 범주가 4개이면 가변수는 몇 개일까요?

  • 가변수는 (범주 개수 − 1)개
  • 모두 0인 범주가 기준이 됩니다.

범주가 4개인 혈액형에 0, 1, 2, 3을 할당하면 선형 증가를 가정하게 되어 적용할 수 없습니다. 대신 0 또는 1인 가변수를 (범주 개수 − 1) = 3개 준비해 {0, 0, 0}을 A형, {1, 0, 0}을 B형처럼 할당합니다. 범주 개수가 아닌 (범주 개수 − 1)개로 하는 것은 다중공선성을 피하기 위해서입니다. 회귀계수 b₁, b₂, b₃는 각각 B형, O형, AB형이 기준인 A형과 얼마나 다른지를 나타내며, 결과는 분산분석과 일치합니다.

다음 질문집단 비교에 양적 변수를 더하면?

4-4 공분산분석

Q키를 고려하면 운동 효과가 더 잘 보일까요?

  • 공분산분석: 분산분석 + 양적 변수
  • 추가하는 양적 변수가 공변량입니다.

분산분석에서는 집단이 설명변수, 양적 변수가 반응변수입니다. 여기에 반응변수에 영향을 주는 양적 변수 데이터가 함께 있을 때 쓰는 방법이 공분산분석이며, 추가한 양적 변수를 공변량이라 합니다. 운동 여부만 보면 차이는 −4.58kg, p = 0.14였지만, 키를 공변량으로 넣은 [몸무게] = a + b₁ × [운동] + b₂ × [키] + ε에서는 −3.60kg, p = 0.028로 유의했습니다. 키에 따른 흩어짐을 설명한 덕분에 검정력이 높아진 것입니다.

다음 질문공분산분석은 언제나 쓸 수 있을까?

4-4 공분산분석

Q공분산분석은 언제 쓸 수 있을까요?

  • 조건 ① 집단 간 기울기가 다르지 않을 것
  • 조건 ② 공변량의 기울기가 0이 아닐 것

공분산분석에는 사용 조건이 있습니다. 첫째, 집단 간 회귀의 기울기가 서로 다르지 않아 회귀직선이 평행해야 합니다. 이는 상호작용이 없다는 뜻으로, 상호작용 검정이 유의하지 않으면 조건을 만족한다고 봅니다(이 데이터 p = 0.48). 둘째, 회귀계수가 0이 아니어야 합니다. 0일 때는 공변량 없이 일반적인 분산분석을 하며, 기울기 검정이 유의하면 만족한 것으로 봅니다(키 p < 0.001). 그러면 회귀직선의 차이(절편의 차이)가 집단 사이의 차이가 됩니다.

정리다중회귀의 확장을 정리해 봅시다.
