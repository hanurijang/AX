4-1 왈드 검정과 가능도비 검정

Q일반화선형모형의 회귀계수는 어떻게 검정할까요?

핵심 수학 개념 · 왈드 통계량
z = 추정값 ÷ 표준오차
계산M2의 b: 0.577 ÷ 0.0614 ≈ 9.41 → p < 0.001
해석귀무가설 ‘회귀계수 = 0’을 정규분포로 판단합니다.
  • 왈드 통계량: 추정값 ÷ 표준오차
  • 표본크기가 작으면 신뢰도가 떨어집니다.

귀무값 θ₀에 대한 왈드 통계량은 (θ̂ − θ₀) ÷ SE(θ̂)입니다. θ₀ = 0이면 추정값 ÷ 표준오차가 됩니다. 식별 가능성 등 정칙조건 아래 최대가능도 추정량의 큰 표본 근사로 p값과 구간을 계산합니다. 작은 표본이나 완전분리·경계 파라미터에서는 이 근사가 나쁠 수 있습니다. 가능도비 검정도 모든 경우에 안전한 것은 아니므로 자료 구조와 가정을 먼저 확인합니다.

다음 질문모형 전체는 어떻게 비교할까?

4-1 왈드 검정과 가능도비 검정

Q항을 더한 모형이 정말 더 잘 들어맞을까요?

핵심 수학 개념 · 가능도비 검정
ΔD₁,₂ = −2 × (log L₁* − log L₂*)
기호L*: 최대가능도, 모형 1이 모형 2에 내포됨
계산M2 vs M3: −2 × (−32.15 + 32.07) ≈ 0.16 → p = 0.69
  • 가능도비 검정: 내포 관계인 두 모형 비교
  • ΔD가 크면 대립가설 모형이 더 잘 맞음

같은 관측·반응변수·가능도 정의로 적합한 내포 모형을 비교합니다. 제한 모형에 항을 더한 모형의 최대 로그 가능도는 더 작아지지 않아 ΔD = 2(log L큰* − log L작은*) ≥ 0입니다. 내부 파라미터·식별 가능성 등 정칙조건 아래 귀무분포는 추가 파라미터 수를 자유도로 하는 카이제곱분포로 근사합니다. M2와 M3의 ΔD ≈ 0.16은 이차항의 개선 증거가 약하다는 뜻이며, 계수가 정확히 0이라는 증명은 아닙니다.

4-1 왈드 검정과 가능도비 검정

QΔD가 충분히 큰지는 어떻게 판단할까요?

  • 귀무가설이 옳을 때의 ΔD 분포와 비교
  • 모수적 부트스트랩이나 카이제곱 근사로

이 예는 모수적 부트스트랩입니다. 제한 모형 M2를 적합한 뒤 설명변수 x를 고정하고 추정된 귀무모형에서 반응을 생성합니다. 반복마다 M2와 M3를 모두 다시 적합해 ΔD를 계산합니다. 저장된 1,000회 예의 상위 5% 경계는 약 3.82로, 정칙조건 아래 카이제곱 근사의 3.84와 비슷합니다. 관측 행을 재표집하는 비모수 부트스트랩과 구분하며, 귀무모형 자체가 부적절하면 이 보정도 신뢰하기 어렵습니다.

다음 질문내포 관계가 아니면 어떻게 비교할까?

4-2 AIC

Q잘 맞음과 복잡함을 함께 고려하는 기준은 무엇일까요?

핵심 수학 개념 · AIC
AIC = −2 log L* + 2k
기호L*: 최대가능도, k: 파라미터 개수
계산M2: −2 × (−32.15) + 2 × 2 = 68.3 (최소)
  • AIC: 새 데이터 예측 관점의 정보기준
  • 후보 중 AIC가 최소인 모형을 고릅니다.

AIC = −2 log L* + 2k는 기대 예측 로그 손실을 기준으로 적합도와 복잡함을 함께 평가합니다. k는 추정한 모든 자유 파라미터 수로, 정규 회귀에서는 오차분산도 포함합니다. 내포 관계는 필요 없지만 같은 관측·반응변수에 대해 가능도의 척도와 상수항을 맞춰 비교해야 합니다. 꽃 자료의 후보 중 M2가 최소입니다. AIC 자체가 실제 모형의 확률이나 별도 검증 자료의 평균제곱오차는 아닙니다.

다음 질문파라미터가 많으면 왜 벌점을 줄까?

4-2 AIC

Q파라미터가 많은 모형은 왜 조심해야 할까요?

  • 과대적합: 지금 데이터에만 무리하게 맞춤
  • 잔차는 작아도 새 데이터 예측이 나빠짐

9개 점에서 7차식은 잔차제곱합을 140.8에서 20.3으로 줄이지만, 저장된 새 데이터 평가 예의 오차는 18.9에서 67.5로 커집니다. 학습 자료에 더 잘 맞는 것만으로 예측이 좋아지지는 않습니다. 이 예는 분산까지 세면 k = 9로 n = 9에 가까워 AIC 근사의 한계를 보입니다. AICc도 적용 조건을 확인해야 하며, 분모가 0 이하이면 해결책이 되지 않습니다. 더 단순한 후보와 적절한 검증을 검토합니다.

다음 질문AIC를 쓸 때 주의할 점은?

4-2 AIC

QAIC가 최소인 모형이 곧 실제 모형일까요?

  • AIC 최소 ≠ 실제 모형
  • 선택 후 추론에는 선택 과정도 반영

AIC 최소 모형이 참이라는 보장은 없으며, AIC는 일반적으로 모형 선택의 일치성을 보장하지 않습니다. 또한 같은 자료에서 여러 후보를 골라 놓고 선택 과정을 무시한 보통의 p값을 보고하면, 명목 유의수준이나 구간의 포함률이 유지되지 않을 수 있습니다. 검정과 예측을 함께 다룰 수는 있지만 사전 분석 계획, 자료 분할·독립 검증, 선택을 고려한 추론 등으로 선택의 영향을 다뤄야 합니다.

다음 질문실제 모형을 고르는 기준은?

4-3 BIC

Q후보 중 실제 모형을 고르려면 어떤 기준을 쓸까요?

핵심 수학 개념 · BIC
BIC = −2 log L* + k log n
기호n: 표본크기, log: 자연로그
계산M2: 64.3 + 2 × log 20 ≈ 64.3 + 6.0 = 70.3 (최소)
  • BIC: 정칙조건 아래 주변가능도 근사
  • 일치성에는 후보 구성 등 조건이 필요

BIC = −2 log L* + k log n은 정칙조건에서 베이즈 주변가능도를 근사하는 기준이며, 값 자체가 사후확률은 아닙니다. 고정된 유한 후보에 참모형이 포함되고, 식별 가능성 등 정칙조건과 적절한 사전분포 조건을 만족하면 모형 선택의 일치성을 가집니다. 유한 표본에서 참모형을 보장하지는 않습니다. 저장된 1,000회 예에서 n = 1,000일 때 선택 비율은 AIC 약 0.75, BIC 약 0.99였습니다.

다음 질문AIC와 BIC는 어떻게 가려 쓸까?

4-3 BIC

QAIC와 BIC는 언제 무엇을 쓸까요?

  • 예측 분포의 성능 → AIC의 관점
  • 후보 모형의 증거 → BIC의 관점

새 자료의 예측 분포를 중시하는지, 정해 둔 후보 사이의 모형 증거를 비교하는지에 따라 기준을 정합니다. 현상이 단순하면 BIC, 복잡하면 AIC라는 구분은 경향을 설명하는 직관일 뿐 규칙이 아닙니다[1]. 후보 구성과 각 기준의 가정, 검증 자료의 예측 성능을 함께 봅니다. 꽃 자료에서는 두 기준이 모두 M2를 골랐지만, 그 선택만으로 참모형이나 인과관계를 확인한 것은 아닙니다.

4-4 그 밖의 정보기준

QAIC와 BIC를 쓰기 어려운 경우에는 무엇을 쓸까요?

  • AICc: 모형·표본 크기 조건 확인
  • WAIC는 예측, WBIC는 모형 증거

정보기준은 계산 방법뿐 아니라 목표도 다릅니다. AICc는 특정 모형에서 AIC의 소표본 편향을 보정하며 적용 조건이 있습니다. DIC는 사후분포의 편차를 이용하지만 비식별·다봉 분포 등에서 주의가 필요합니다. WAIC는 관측 단위별 사후 예측 로그밀도를 바탕으로 예측 성능을 평가합니다. WBIC는 주변가능도에 대응하는 자유에너지를 근사해 모형 증거를 비교합니다. WAIC와 WBIC를 같은 목적의 대체품으로 취급하지 않습니다.

4-4 그 밖의 정보기준

Q표본이 작으면 AICc로 항상 해결될까요?

  • 분모가 0 이하이면 표준식을 쓰지 않음
  • 모든 GLM에 같은 보정식을 쓰지는 않음

정규·등분산 오차의 최대가능도 회귀에 쓰는 표준식입니다. n = 9인 예에서 1차식은 AIC 56.29에 4.8을 더합니다. 6차식(k = 8)은 분모 0, 7차식(k = 9)은 분모 −1이므로 이 AICc를 적용할 수 없습니다. 음수 분모로 계산해 작은 값을 얻었다고 좋은 모형으로 선택하면 안 됩니다.
